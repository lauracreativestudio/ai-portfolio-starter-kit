# AI Portfolio documentation (v1.1)

See also root `CHANGELOG.md` and `QA-REPORT.md`.

## Open locally

```bash
python3 -m http.server 8000
```

- German: http://localhost:8000/  
- English: http://localhost:8000/en/  

Language switch: **DE | EN** in the top navigation (right side).

## What the demo does

Local JavaScript classifies your text by keywords and shows a sample analysis. No external AI, no network call with your text.

## What the form does

Validates required fields and shows a preview confirmation. Data is not stored or transmitted.
