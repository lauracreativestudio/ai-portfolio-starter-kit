# Product contents — AI Portfolio Buyer Starter Kit (draft v1)

## Purpose

Help an AI freelancer personalize a bilingual (DE/EN) static showcase website and prepare it for publication **without hiring a developer**.

This is the **first buyer-kit draft**. It still requires human review before any commercial sale of the package.

## Package layout

```
├── PRODUCT-CONTENTS.md          ← this file
├── buyer-kit/
│   ├── BUYER-QUICK-START.md     ← start here
│   ├── CUSTOMIZATION-GUIDE.md   ← edit text, prices, simple colors
│   ├── TEXT-KIT.md              ← example EN copy for 3 freelancer types
│   ├── PROMPT-PACK.md           ← safe prompts to adapt copy
│   └── LAUNCH-CHECKLIST.md      ← before go-live
├── site-config.js             ← EDIT THIS to personalize (DE+EN)
├── index.html                   ← German homepage
├── en/index.html                ← English homepage
├── impressum.html / datenschutz.html
├── en/impressum.html / en/datenschutz.html
├── styles.css / script.js
├── assets/fonts/
├── README.md, CHANGELOG.md, QA-REPORT.md, docs/
```

## File purposes

| File | Purpose |
|------|---------|
| **BUYER-QUICK-START.md** | What you got, limits, how to preview, pre-publish needs |
| **CUSTOMIZATION-GUIDE.md** | Where to edit brand, services, prices, contact, colors |
| **TEXT-KIT.md** | Example English copy (automation / content / consultant) — labelled as examples |
| **PROMPT-PACK.md** | Prompts that forbid invented credentials and results |
| **LAUNCH-CHECKLIST.md** | Testing and honesty checks before launch |
| **Website files** | Unchanged v1.1.1-FINAL static site |

## Critical product facts (do not market otherwise)

- The **demo** is local simulated logic in `script.js` — **not** a real AI application.  
- The **contact form** does not send or store messages unless you later connect a real service.  
- **Legal pages** contain placeholders — the buyer must supply real data.  
- **No** AI API keys, backend, or paid dependency are required to preview the site.
