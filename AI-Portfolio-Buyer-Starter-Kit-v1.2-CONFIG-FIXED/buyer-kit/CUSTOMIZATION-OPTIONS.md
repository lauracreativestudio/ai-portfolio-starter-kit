# Why site-config.js? (short comparison)

| Option | Idea | Pros | Cons |
|--------|------|------|------|
| **A — Only HTML comments** | Mark sections in many files | No JS | Beginner must edit 6+ files |
| **B — site-config.js (chosen)** | One config file, pages read it | One place, DE+EN together | Must keep valid JS quotes/commas |
| **C — Build tool / CMS** | React, WordPress, etc. | Powerful | Not beginner, not this package |

This package uses **Option B**.
