# Launch Checklist

Work top to bottom. Check each box when done.

---

## A. Content and identity

- [ ] Brand name updated on DE and EN (header + footer)  
- [ ] Headlines and intros match **your** real offer  
- [ ] Services describe only what you can deliver  
- [ ] Prices updated or clearly “on request”  
- [ ] Example / demonstration blocks not presented as real client results  
- [ ] Contact placeholders reviewed (form examples are not a working inbox)

## B. Legal pages (owner responsibility)

- [ ] `impressum.html` — real provider data or still clearly placeholder (do not publish fake data)  
- [ ] `en/impressum.html` — aligned with DE facts  
- [ ] `datenschutz.html` / `en/datenschutz.html` — match real tech (static site, no tracking unless you add it later)  
- [ ] You understand this kit does **not** provide legal advice or guarantee compliance  

## C. Desktop checks

- [ ] `index.html` opens and scrolls through all sections  
- [ ] `en/index.html` opens  
- [ ] **DE | EN** switch works both ways  
- [ ] Nav anchors work (Services, Pricing, Demo, FAQ, Contact, etc.)  
- [ ] Footer links to Impressum / Privacy work in both languages  

## D. Mobile checks

- [ ] Phone or browser responsive mode (~375px width)  
- [ ] Menu button opens and closes  
- [ ] Text is readable; no major horizontal scrolling  
- [ ] Buttons and form fields usable  

## E. Demo and contact form (critical honesty)

- [ ] Demo: empty input shows a clear message  
- [ ] Demo: normal input shows a **simulated** result  
- [ ] You accept: demo uses **local simulated logic**, not a real AI model or API  
- [ ] Form: required fields validate in the browser  
- [ ] Form success text still says **preview** / not stored / not sent  
- [ ] You accept: the form **does not send messages** until you add a real submission service yourself  

## F. Technical package

- [ ] Folder `assets/fonts/` uploaded with the site  
- [ ] Folder `en/` uploaded with the site  
- [ ] `styles.css` and `script.js` load (no broken layout)  

## G. Hosting and publication

- [ ] Static host chosen (provider terms reviewed by you)  
- [ ] Test URL checked on phone and desktop  
- [ ] HTTPS works on the live URL (most hosts provide this)  
- [ ] After go-live: click DE/EN and legal links on the **live** domain  

## H. Final honesty check

- [ ] Live site does not claim a real AI backend for the demo  
- [ ] Live site does not claim the form emails you unless that is true  
- [ ] No invented testimonials or results  

---

If any box in **E** or **H** fails, fix wording before promoting the site to clients.
